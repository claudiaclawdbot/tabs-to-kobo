Setup

Install once, then use the popup

1

Install the companion

Clone the repo and run the setup command. On macOS, double-click `macos/Install Tabs to Kobo.command` if you prefer a guided window.

git clone https://github.com/claudiaclawdbot/tabs-to-kobo.git
cd tabs-to-kobo
npm run setup
npm run service:install
2

Load the browser extension

Open Chrome's extension page, enable Developer mode, click Load unpacked, and choose the `extension` folder.

3

Find the Kobo URL

Use the extension's Copy Kobo URL button, or double-click `macos/Restart Tabs to Kobo.command` to print it.

Daily use

A small loop that stays out of the way

  1. Put the articles you want in one Chrome window.
  2. Click Tabs to Kobo, then Create EPUB from this window.
  3. On the Kobo, open the web browser and visit the same-Wi-Fi library URL.
  4. Tap the newest EPUB. Kobo downloads it into My Books.

Good fit

Built for window-sized reading piles

Instapaper is better for saving single articles to a service account. Tabs to Kobo is better when you have a whole browser window that should become one offline book.

Tabs to Kobo

  • Creates one EPUB file
  • Keeps tab order
  • Works without a cloud account
  • Uses Kobo's browser on Clara BW

Native read-later apps

  • Sync individual articles
  • Depend on a service account
  • May vary by Kobo model
  • Usually hide the final file

Privacy

The boundary is intentionally boring

Local build

The extension sends tab titles and URLs only to the companion on your own computer.

No cookies

The companion fetches public page HTML without browser cookies or saved credentials.

Wi-Fi downloads

Devices on your trusted home network can list and download generated EPUBs, but cannot trigger builds.
