# macOS helper launchers

These files are optional double-click helpers for users who do not want to run Terminal commands.

- `Install Tabs to Kobo.command`: installs dependencies, installs the login service, opens the local EPUB library, and opens Chrome's extension page.
- `Restart Tabs to Kobo.command`: restarts the login service, opens the local EPUB library, and prints the Kobo browser URL.
- `Uninstall Tabs to Kobo Service.command`: removes only the macOS login service.

If macOS says the file cannot be opened, right-click it, choose Open, and confirm once.
